Parte E: Evaluación final de modelos

E.1 Objetivo

Evaluar el modelo seleccionado en la Parte D sobre el conjunto de prueba cronológicamente posterior, sin volver a entrenar ni elegir hiperparámetros con esos resultados.

E.2 Carga del modelo y datos de prueba

Código 
from pathlib import Path
import json
import joblib
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.metrics import (
    roc_auc_score, average_precision_score, brier_score_loss,
    confusion_matrix, classification_report, RocCurveDisplay,
    PrecisionRecallDisplay, ConfusionMatrixDisplay
)
base = Path("../outputs/models")
modelo = joblib.load(base / "modelo_final.joblib")
metadata = json.loads((base / "modelo_metadata.json").read_text(encoding="utf-8"))
prueba = pd.read_parquet("../data/processed/test_raw_split.parquet")
columnas = metadata["caracteristicas"]
y = prueba["incumplimiento"]
prob = modelo.predict_proba(prueba[columnas])[:, 1]
print("Modelo:", metadata["modelo"])
print("Registros de prueba:", len(prueba))
print("Incumplimiento observado (%):", round(100*y.mean(), 2))

metricas = pd.DataFrame([{

    "ROC_AUC": roc_auc_score(y, prob),
    "PR_AUC": average_precision_score(y, prob),
    "Brier": brier_score_loss(y, prob),

display(metricas.round(4))
Modelo ROC_AUC PR_AUC Brier Prevalencia
0 Random_Forest 0.6974 0.3761 0.1568 0.2185

La PR-AUC debe interpretarse junto con la prevalencia observada. Un buen ROC-AUC no garantiza probabilidades bien calibradas ni utilidad para una decisión de crédito.

E.6 Calibración por deciles

Código 
cal = pd.DataFrame({"real": y.to_numpy(), "probabilidad": prob})
cal["decil"] = pd.qcut(cal["probabilidad"].rank(method="first"), q=10, labels=False)
resumen_cal = cal.groupby("decil").agg(
    cantidad=("real", "size"),
    probabilidad_media=("probabilidad", "mean"),
    tasa_real=("real", "mean")
).reset_index()
display(resumen_cal.round(4))
fig, ax = plt.subplots(figsize=(6, 5))
ax.plot([0, 1], [0, 1], "--", color="gray", label="Calibración ideal")
ax.plot(resumen_cal["probabilidad_media"], resumen_cal["tasa_real"], marker="o", label="Modelo")
ax.set(xlabel="Probabilidad predicha", ylabel="Frecuencia observada", title="Calibración por deciles")
ax.legend(); plt.tight_layout(); plt.show()

E.8 Interpretación y límites de generalización

Comparar métricas de validación y prueba después de ejecutar los cálculos. Una caída de desempeño puede deberse a cambios de distribución, diferencias temporales o sesgo de selección. El dataset excluye préstamos activos, de modo que el desempeño estimado no representa necesariamente la predicción de todos los préstamos recién originados. No utilizar las métricas de prueba para cambiar el modelo y volver a reportar la misma prueba como evaluación independiente.
